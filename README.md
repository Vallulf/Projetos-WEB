O conhecimento ilumina caminhos onde a ignorância vê paredes.
Este repositório documenta minha evolução durante o curso de HTML5 e CSS3 do Gustavo Guanabara.

Meu objetivo não é apenas assistir às aulas, mas transformar cada conceito aprendido em prática real. Ao final de cada módulo, desenvolvo um projeto próprio para consolidar os conhecimentos adquiridos e criar um portfólio que reflita minha evolução como desenvolvedor.

🎯 Objetivos deste repositório
Praticar todos os conceitos estudados em HTML e CSS.
Desenvolver projetos progressivamente mais completos.
Registrar minha evolução como programador.
Criar um portfólio com aplicações reais.
Construir uma base sólida para avançar para JavaScript, desenvolvimento Front-end e, futuramente, Backend.
📚 Metodologia de estudo

Após concluir cada módulo do curso, desenvolvo um projeto aplicando os conteúdos aprendidos, incluindo:

Estruturação semântica com HTML5.
Estilização com CSS3.
Responsividade.
Flexbox e Grid Layout.
Animações e efeitos visuais.
Boas práticas de desenvolvimento web.
📈 Evolução contínua

Cada projeto representa uma etapa da minha jornada. Conforme avanço nos estudos, os projetos se tornam mais completos, modernos e desafiadores, demonstrando meu crescimento técnico e minha dedicação à programação.

Este repositório será atualizado constantemente até que eu alcance um nível profissional de desenvolvimento web.
